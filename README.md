Task Manager Web Application

Overview

A simple, browser-based Task Manager application developed using HTML, CSS, and JavaScript. The application allows users to organise their daily activities by creating tasks, marking them as completed, and deleting tasks when they are no longer needed.

The project demonstrates fundamental frontend development skills, including DOM manipulation, event handling, form validation, and browser local storage.

Features

* Add Tasks: Create new tasks through a simple input interface.
* Complete Tasks: Mark tasks as completed when finished.
* Delete Tasks: Remove tasks that are no longer needed.
* Input Validation: Prevent empty tasks from being added.
* Local Storage: Save tasks in the browser so they remain available after refreshing the page.
* Dynamic Interface: Update the task list without reloading the page.

Technologies Used

* HTML5 – Application structure
* CSS3 – Styling and layout
* JavaScript – Application functionality and interactivity
* Browser Local Storage – Task data persistence

Project Purpose

This project was developed to strengthen my practical understanding of frontend web development and JavaScript programming. It provided hands-on experience in building interactive web interfaces, managing user input, manipulating webpage elements, and storing data locally in the browser.

Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your web browser.
4. Start adding and managing your tasks.
